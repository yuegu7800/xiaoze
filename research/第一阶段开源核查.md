# 小泽第一阶段 · 开源参考与许可证核查

核查日期：2026-11-11。通过 GitHub 公共 API 获取默认分支、提交SHA、最近推送时间及归档状态，下载固定版本的许可证、README和少量实际代码。不是仅凭项目简介或以往印象；没有运行这些项目、安装依赖或验证其宣传性能，也没有向外发送本机聊天、配置或人物记忆。
