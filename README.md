# 小泽 / Xiaoze

长期陪伴虚拟角色的本地 Python 项目，由原阿澄项目逐步演进。保留人格、选择性记忆、分人关系、群私上下文、本地主动表达与反馈能力。

**本项目于 2026-11-19 保存并按维护者要求公开。微信接入路线仍在研究讨论，不代表已交付可靠的后台微信机器人。** 最新保存范围及继续工作的停止点见 [进度保存说明](docs/GitHub保存进度2026-11-19.md)。

已有记录包含 **12 个编号阶段 + 5 个微信整合批次（A—E）+ 后续专项修复与路线研究**。完整时间线、各阶段内容和原始验证材料见 [更新日志与阶段索引](CHANGELOG.md)。历史阶段由文档回溯整理，并非 12 个 GitHub 发行版。

## 当前能力

- 本地连续文字聊天：流程模拟与用户手动触发的模型试聊；本机 API 配置可通过 Windows DPAPI 保存。
- 稳定人格与固定主人规则、按人物与场景区分的关系和上下文。
- 本地有界记忆、有限规则召回、人工确认、更正、抑制与删除、来源链和预算管理。
- 人工话题、主动候选、沉默判断与本地采用；窗口内明确启用的自动开口。
- 逐条回复反馈、当前快照预览和仍可用的本进程轮次取数证据。
- 原微信私聊、群聊和双会话兼容层及小泽核心整合代码。

本地试聊已有用户正向反馈，但不能据此承诺所有场景的人格效果。微信兼容层依赖前台视觉和键鼠，曾出现串场及连续收发问题；已有保护与离线回归，**尚未完成可靠持续收发验收，也不具备已验证的纯后台能力**。AIRI 形象/语音、自动加好友和朋友圈发布尚未接通。

## 本地文字入口

现有电脑使用 `启动小泽本地试聊.cmd`，窗口关闭后本地自动开口停止。原 CMD 启动器包含原电脑 Python 的绝对路径；从 GitHub 恢复到其他电脑时，不应直接假定该路径存在。

新的 Windows 环境可使用带 Tkinter 的 Python 3.12，为本地文字入口建立独立环境：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\python.exe -m pip install requests
.\.venv\Scripts\python.exe launch_local.py --check
.\.venv\Scripts\python.exe launch_local.py
```

上述是基于当前导入结构的恢复指引，本次未重新创建干净环境验证。实际模型调用由用户配置并主动触发；恢复仓库不会恢复密钥、聊天和记忆。

微信兼容入口还依赖原电脑项目外的 Xiaoli 桌面适配器、Windows 相关库及匹配运行环境，见 [原使用说明](使用说明.md)。本仓库没有打包这些第三方源码、虚拟环境、OCR 模型和安装包；换电脑后不能保证微信入口直接启动。不要把导入检查通过当作真实微信可用。

## 保存与隐私边界

仓库仅保存源码、虚构测试、人物设定及开发文档。`data/`、`.local-xiaoze/`、API 凭据、真实聊天和人物记忆、日志、截图、快捷方式备份及下载的第三方研究副本均不纳入版本控制。本机这些文件不因本次上传而删除。

开发文档保留既有角色称呼、确认过的显示名和历史机器路径，供恢复理解使用；它们不构成账号认证。公开前已检查现有提交的文件范围及常见凭据样式。第三方下载源码未纳入本仓库；有关借鉴、上游依赖和许可的历史核查见 research 与各阶段文档。

本仓库当前公开可读，尚未添加项目整体的开源许可证；公开可见不等于授予任意复制、修改或分发许可。各第三方项目继续适用其自身许可证。

## 继续工作的约定

用户当前要求先讨论目标、能力和接入路线，再开始开发。群聊、多人私聊、独立身份及不干扰日常桌面是重要目标；iLink、PAD 接口和隔离 Windows 路线仍需比较与实证。恢复本仓库不自动安装适配器、启用开发接力、监听微信或发送消息。
