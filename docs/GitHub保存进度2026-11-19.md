## 最新路线讨论

用户目标不是仅有单人聊天入口：希望独立身份在普通微信群和多个人物私聊中长期相处，不占日常桌面，随后按接口能力扩展语音、表情、朋友圈等。

1. iLink/ClawBot：Tencent/openclaw-weixin 有 HTTP 及扫码渠道，MIT；当前核对支持优先研究单聊，普通微信群未证明可用。不能以 group_id 字段推定服务端提供群事件，也不能把绑定机器人当成接管原个人账号。
2. PAD：WeChatPadPro 声称普通账号、群/联系人/朋友圈接口；LangBot 有专门接入说明。当前公开目录及部署使用现成镜像，未取得完整底层源码/许可、准确授权与可用性证明。可以研究，不能宣称已可自行维护全部底层。
3. Windows 桌面适配器：保留隔离 Windows/备用电脑作为候选。wxauto 的版本支持和桌面依赖须具体确认；虚拟机只隔离日常桌面，不自动消除串发或让主机关机后继续运行。
4. Hook/旧版协议：wxhelper/WeChatFerry 的旧版本支持不能推定兼容当前微信；自行适配属于专门维护，不作为常规小补丁承诺。

我们可以补接入层路由、稳定身份绑定、串行处理、去重恢复、界面、人格和记忆；不能仅改业务代码让服务端下发它没有开放的群事件，或修复没有源码的外部底层。先查明候选身份/会话范围、群与成员标识、主动发送限制、许可和故障维护责任，再决定最小真实验证。
