# 小泽按钮与分项测试：白话指南

更新：2026-11-12。适用于当前本地试聊窗口。你已反馈模型试聊可以、效果不错；下面帮助分别体验记忆、分人关系和本地主动开口，不要求重做历次开发。

## 先明白：阶段名字不是要依次通关

第一至九阶段是开发进度，当前窗口已经包含前面完成的功能。下拉框里“第四阶段”“第五阶段”等只是测试台词的名字，不是不同版本，也不用先升级才能测试。

想看她说话的效果，用“模型试聊”。想熟悉按钮、避免模型费用，可先用“流程模拟”；普通模拟回复是固定文字，不能拿它判断自然程度。模型模式发送消息或点击“评估一次”且通过本地门槛时，可能消耗一次模型请求；查看、标记话题、维护记忆、反馈和采用不额外调用模型。

## 这几个按钮分别是什么

| 按钮 | 通俗含义 | 什么时候用 |
|---|---|---|
| 记忆 / 证据 | 看她保存了谁的哪些资料，能改、停止取用或删除，也能预览现在可能取用什么 | 测试记忆时用 |
| 话题 / 主动草稿 | 先告诉系统某件事以后还能聊，再手动让小泽考虑一次要不要开口，生成待你确认的草稿 | 测试本地开口、群聊候选、朋友圈文字草稿时用 |
| 记录体验 | 给已提交的某一条回复写评价和期望 | 觉得回复好或有问题时用；从该回复下“评价这条回复”进入更容易选对 |
| 升级v1记录 | 把很早版本的本地试聊记录接到现在的管理流程，旧偏好需审核 | 有旧版记录、确实要迁移时才用；新用户暂时不用点 |
| 升级v2来源记录 | 把旧内部v2结构升级成现在的v3，让后续回复能记清来源 | 只有程序提示旧v2只读时才考虑；现在能正常发送一般不用点 |

“升级”升级的是旧数据格式，不是模型、人格或功能。文件名即使带v2也不代表内部仍是v2，当前新文件直接使用v3。两个升级按钮都不会下载新模型。

“独立体验区”相当于另开练习本，适合用虚构材料测试。勾选后，脚本名称、模拟/模型模式、长期记忆开关、话题开关的组合会决定使用哪份练习记录；改变组合可能看到空白。每组测试开始前选好，组内保持一致。普通非独立区的两个记忆开关仅改变取用，不会另开一份库。练习记录并非关闭就消失，仍保存在本机；不要把它当临时无痕模式。

## 测试一：记忆能保存、改正吗

1. 主窗口选“模型试聊”→“与孤月大人私聊”→“孤月大人”。选择“主人：偏好与更正”，勾独立体验区，保持“召回长期记忆”“话题延续”勾选。
2. 输入“我不喝咖啡”，发送；等完成后点“记忆 / 证据”，看当前人物的有效资料里是否有这个明确偏好。没有时先核对模式、人物和筛选；仍没有就记为问题，不把模型口头说“记住了”当保存证明。
3. 关闭面板，发“想找点喝的，你记得我的口味吗”。观察她有没有自然考虑不喝咖啡，而不是机械念档案。
4. 再发“更正，之前说错了，我喝咖啡”，回记忆面板看当前有效结论是否改变。历史里可能仍能看到旧条目，这不等于仍在使用旧结论。
5. 若想测试人工维护，选中有效条目，点“更正内容…”进入编辑，写新内容，再点“保存所绑定条目的修改”。刷新或换筛选不会替你把编辑改到别条。

第二句刚刚说过的内容，也可能从近期聊天得知；本测试证明不了跨很久的长期召回。不要为推过12轮窗口连发十几次付费请求；跨窗口样例可按第五阶段使用说明使用`stage5_demo.py`。

## 测试二：两位朋友和主人的态度会分开吗

1. 换到“朋友：不同边界”脚本，独立体验区保持勾选；主场景选本地模拟群聊。
2. 发言者选小林，发“小泽，别怼我”。
3. 发言者换小乔，发“我可以接受友善的玩笑”。
4. 发言者换孤月大人，发“我把小说主角的名字写反了，救命”。
5. 观察：小林的拒绝应得到尊重；小乔允许友善玩笑，不等于每条都必须被调侃；对主人仍温柔尊重，不能把对小乔的方式套过来。

这是一间本地“排练群”：你用发言者下拉框扮演三个人，不需要真实微信群，不会向微信发消息。身份由本机选择，不由输入里自称“我是主人”决定。

## 测试三：私聊资料会不会串出去

选“记忆：私群隔离”脚本，在相同练习组合内逐句载入并发送：小林私聊说“我喜欢蓝色纸风筝”→切本地群聊由小林问“你记得我喜欢什么吗”→切小乔私聊问同一句。

正常预期：群和小乔私聊不能直接拿小林私聊内容当已知资料。若其他资料原本也含相同内容，会干扰判断，因此使用虚构材料及独立体验区。此测试的本地结果不代表已测试真实微信身份认证。

## 测试四：让她主动开口一次，再接话

现在的“主动”需要你按一下，尚不会在后台等着定时找你。完整流程是“留个话题→让她考虑一次→有草稿才确认说出→你接着回”。

1. 选“第四阶段：本地开口与接话”，确认主人私聊、人物为孤月大人；发送“虚构小说纸船的结尾还没想好”，等回复完成。
2. 点“话题 / 主动草稿”，再点右上“启用本场景话题与草稿”。这个启用只是当前本地功能开关，不会启动后台。
3. 在“以后可以接着聊”页，找到“近期发言 / 有效记忆来源”下拉框，选刚才那句。原文预览出现后，用鼠标选中“纸船的结尾还没想好”这段连续文字，再点“用上方选中片段作证据”。
4. 主题可写“纸船结尾”，待续方向写“聊聊主角离开以后朋友怎么反应”；有效天数先用7、最早再考虑分钟用0。点“标记并确认”。相当于给她留了一张有出处的便签，不是编一段共同经历。
5. 切到“看看小泽现在想说什么”页，选“私聊草稿”和“孤月大人”，点“评估一次（可能调用一次模型）”。
6. 若有草稿，选中它，点“在本地对话中说出（仅私聊/群聊）”。关闭面板，聊天中会出现她的一条独立开口。
7. 你再发“我想试试你刚才说的那个方向”，看她能否接住那句，而不是重复问原问题。

选择沉默也是正常结果：没有有效话题、还没到时间、边界不允许、已有待处理草稿、10分钟评估冷却，或模型认为不适合，都可能让她先不说。看底部原因，不要连续点击期待一定出草稿。选择沉默不保证一定零费用：本地门槛挡住时不请求模型，模型收到后才选择沉默仍可能计费。

想测“结束后不再打扰”，关面板后在聊天发“这个话题不要再聊了”，再查看话题状态并评估一次。它不应借主动草稿继续纠缠；若此时仍在冷却，沉默本身不能单独证明停止表达生效，还需看状态/原因。

“复制草稿”仅复制；“在本地对话中说出”才把私聊/群聊草稿放进当前聊天，两者都不发微信。“丢弃并暂停同源话题”还会暂停该话题，之后需要明确重新开启才能再考虑。

## 可选：朋友圈文字草稿

在草稿页用途选“朋友圈草稿”，下方写自编的公开素材，例如“虚构随想：今天想到一个关于纸船和告别的故事”，点“确认以上为公开素材”，然后手动评估。只用你确认的公开素材，不要把私人聊天放进这里。

有草稿可查看或复制，不能点私聊/群聊的采用按钮来发布朋友圈。当前程序没有发布能力，也没有后台自动发朋友圈。

## 测试五：记录一条体验

点目标回复下的“评价这条回复”，默认先看中文摘要。选“自然合适”或实际遇到的问题标签，期望写具体一点，例如“我说累了，先陪我聊，不要又列三个任务”，再保存。

它是一张本地问题便签，不会立即训练模型。选别轮时旧反馈仍属于原轮；切回可继续，想改评新轮先明确放弃。保存反馈或查看摘要不调用模型。旧证据过期或没有清单就按未知处理，不把当前预览补成那轮实际输入。

## 建议顺序

你已经试过自由聊天，下一次先做“咖啡偏好→更正”与“主动开口→接话”两组即可，再按兴趣测试朋友和私群隔离。无需一次全部完成，也不用点两个升级按钮。

具体按钮已按当前代码核对；本指南不是本轮代你运行的模型测试结果。反馈你实际做了哪几组、是否成功、遇到哪一句问题，就能逐步缩小需要优化的范围。
# 新增：保存API配置（2026-11-12）

后续追加修复：主动候选现已明确请求JSON对象格式。需要关闭旧窗口重开才能生效；点一次“评估一次”后，生成的草稿会出现在列表里，点该行查看。也可能合法选择沉默。真实提供方待你手动确认，详见[修复说明](主动候选JSON故障修复.md)。

重开本地试聊窗口一次，填好接口、模型、Key后，点击“保存本机API配置”。看到“已加密保存到本机”即可；以后启动自动填入，不会自动联网，仍需你选择模型试聊并点击发送或评估。旧窗口不会自动出现新按钮。本功能覆盖本说明旧版本中“配置仅保留在窗口内”的描述。

修改配置后需要再次点击保存。“忘记已保存配置”只删除本程序保存的配置并清空三栏，不删除聊天，也不撤销服务商的Key。配置由当前Windows用户加密，换电脑或Windows用户可能需要重填。保存只做本地格式检查，不验证服务商是否接受接口和密钥。

主动开口若仍提示“候选格式无效”，说明这次候选未成功生成；保存API配置不等于修复候选格式。不要用反复点击代替排查，每次真实评估可能产生费用。
