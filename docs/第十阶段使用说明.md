# 第十阶段：窗口内可控自动开口

> 后续可靠性修复已完成，见[第十一阶段使用说明](第十一阶段使用说明.md)。本页的开启步骤、默认时机与配额继续有效。

第十阶段已实现并通过虚构资料/mock验证。前一阶段按用户“验收可以”的反馈接续，不要求重做旧验收。本阶段的真实自动使用效果尚待用户自选体验，开发没有开启正式自动运行。

## 开启方法

1. 关闭旧版本窗口，通过原`启动小泽本地试聊.cmd`重开，不需要打开微信、安装依赖或迁移资料。
2. 选择“与孤月大人私聊”。默认“流程模拟”可以演练；要体验真实语言，自行选择“模型试聊”，核对本机配置。读取已保存的API配置只填栏，不会开启自动模式。
3. 先按原流程在“话题 / 主动草稿”面板启用本场景扩展，选择本场景已有发言或有效记忆中的连续片段，填写主题/待续方向，并“标记并确认”。自动模式不会替你启用扩展、搜集资料或新建话题。已有有效话题可直接使用。
4. 关闭子窗口、处理已有待处理草稿、清空未发送输入，勾选主窗口的**自动考虑开口**。从此刻重新等待10分钟空闲，不会刚开启就请求。
5. 默认只留下草稿。想让本次自动生成的有效草稿直接显示到本地聊天，再勾选**自动加入本地聊天**。它会加入一句本地助手消息，之后可以正常接话；不会发微信，也不代表已读。这个开关不会补采用之前留下的草稿。

只开启第一个开关时，生成后到原“话题 / 主动草稿”面板查看、手动采用或丢弃。丢弃仍暂停同源话题，需要明确重新开启，不会换个措辞继续催问。原手动评估、采用、逐轮反馈入口继续可用。

## 默认时机与上限

| 项目 | 当前规则 |
|---|---|
| 检查间隔 | 约30秒；检查本身不调用模型 |
| 空闲 | 开启后、真实用户操作后至少10分钟，且输入框没有未发送内容 |
| 安静时段 | 北京时间23:00—08:00，不自动请求，也不自动采用 |
| 自动模型请求尝试 | 滚动1小时最多2次，本次程序会话最多6次 |
| 自动加入本地聊天 | 滚动1小时最多2条，本次程序会话最多6条 |
| 未回应限制 | 一次主动开口后，必须在该场景成功提交新的聊天，才允许再自动开口；手动采用也受此限制影响 |
| 模型沉默 | 是成功评估，保留原10分钟评估冷却；不会立即再次请求 |

主窗口状态显示等待原因、自动模型请求尝试次数和剩余额度、自动本地开口次数。这里的配额只针对自动行为，**不包含你手动聊天或手动评估的请求，不是总费用上限或精确账单**。

失败、超时、空白、格式错误、截断、模型沉默和已发出后取消都可能消费服务商费用；发起后不退还自动请求尝试次数。仅被本地门槛挡住、或者本机配置校验失败不计模型请求尝试。流程模拟不发HTTP、不占模型请求次数；模拟中实际自动采用的本地消息计入表达次数。

次数仅在当前Python程序进程内保存，切场景、关闭再开启不会清零；程序退出再启动会重置。两项开关每次启动均关闭。这不是跨重启的每日预算，不能以反复重启作为频率控制。

## 为什么有时不说话

没有有效人工话题、话题/记忆开关关闭、明确想安静、话题结束、冷却、已有待处理草稿、配额不足或尚未回应，都会等待，不一定调用模型。合法沉默也不会变成本地消息。资料数量/来源ID仍不能证明模型理解了资料。

输入或粘贴、点击操作、发送等会重置空闲。只编辑输入、复制、反馈、切场景、重新开启以及自动采用本身都不算回应；必须是该场景成功保存的新聊天。未发送文字即使只有空格也会暂缓。

最小化、打开记忆/话题/反馈等子窗口时暂缓；恢复或关闭子窗后重新等10分钟。程序休眠、长时间未获得调度（超过90秒）后不补跑积攒任务，重新等待空闲。后台的列表/证据刷新不算用户操作，不会因自动刷新永远等不到空闲。

自动只处理当前主人私聊所绑定的Core和模式/体验区，不轮询朋友、群聊、公开草稿或其他Core。这些场景仍手动操作。

## 停止与故障恢复

点击主窗口**停止自动**可同时关闭两项功能。切换模式、场景、人物、体验区、检索开关或修改API配置都会关闭自动；返回原范围也不会重新开启。“暂停 / 作废本轮”同时关闭自动，继续普通聊天不会恢复它。关闭主窗口会取消定时器，程序退出后不运行，没有系统常驻或开机任务。

已发HTTP不能撤回，仍可能计费。生成中开始输入、暂停、停止、切范围或维护来源时，迟到结果不能自动采用，也不会覆盖输入；若草稿此前已提交，它保留为原场景待处理草稿，不在稍后补采用。生成后进入安静时段也不自动采用。

网络、格式或存储错误会停止本次自动会话并显示原因，普通聊天不会因此永久暂停。检查原因、处理已有草稿或本机配置后，由你主动重新开启，再等新的10分钟；没有自动重试、修复请求或排队补偿。

如果提示已提交但显示刷新失败，切换场景或重开窗口恢复原记录，勿为显示问题重复评估/采用。自动采用仍是“本地开口、无普通exchange同等级的直接取数清单”；可逐轮反馈，不能用今天的记忆预览补生成当时的证据。

本阶段未实现微信投递、朋友/群自动轮巡、语音、识图、自动上网、自动成长或系统后台运行。技术边界见[架构与复盘](第十阶段架构与复盘.md)，实际验证见[验证记录](第十阶段验证记录.md)。
