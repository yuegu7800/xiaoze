# 第十二阶段：看懂自动开口的等待状态

第十二阶段已实现并完成虚构/mock验证。原窗口、启动器和开启方式不变；本轮改善的是“现在为什么没开口”，没有调整频率、配额或小泽人格。真实自动体验与语言自然度尚未验证。

## 在哪里看

关闭旧窗口，通过项目根目录的`启动小泽本地试聊.cmd`重开。无需打开微信、安装依赖或迁移资料。自动控制区现在显示当前首要等待原因、必要时的剩余时间和一步操作；下一行显示自动请求尝试与自动本地开口次数。

两项自动开关每次启动仍关闭，保存的API配置只填栏。只有你自己在主人私聊勾选“自动考虑开口”后才运行；默认只留草稿。另勾选“自动加入本地聊天”才会把本次新草稿加入本地对话，不补采用旧草稿，不发送微信，也不代表对方已读。关闭窗口后不运行。

## 常见提示怎么处理

| 当前提示 | 含义与下一步 |
|---|---|
| 等待空闲，还约4分30秒 | 正在等待10分钟空闲门槛。继续等待；到点还需其他条件，不保证开口 |
| 输入框有未发送文字 / 子窗口 / 最小化 | 先完成输入、关闭子窗口或恢复窗口；恢复后重新等10分钟 |
| 安静时段 | 北京时间23:00—08:00不自动评估或采用，显示到08:00的约计时间 |
| 请先启用话题与草稿 | 打开原“话题 / 主动草稿”入口，明确启用本场景扩展 |
| 没有有效话题 / 待确认 / 尚未到接续时间 | 在原入口从已有本场景发言或有效记忆人工标记并确认话题，或等已确认话题到时。不会自动找兴趣或创建话题 |
| 已有待处理草稿 | 去“话题 / 主动草稿”查看、手动采用或丢弃；这个提示本身不代表刚调用了模型 |
| 成功评估后冷却 | 从实际评估提交时刻起冷却10分钟；只有本次自动事务明确返回silent，才注明“模型选择沉默” |
| 等待用户回应 | 已加入一次本地开口；在同场景成功发送新的聊天后才能再自动开口。编辑、复制或评价不算回应 |
| 滚动小时上限 | 显示最早恢复额度的约计时间；到时仍需其余门槛 |
| 本次程序会话上限 | 当前程序会话不再自动执行，没有一小时后恢复的倒计时，不建议反复重启绕过额度 |
| 正在评估 | 等待当前任务结束；不要重复点击。模型模式下已发出的请求无法撤回，可能计费 |
| 错误后停止 | 核对原提示与已有草稿后由你决定是否重新开启；不会自动重试 |

同时存在多个条件时，只显示执行顺序中的首要原因。例如尚未空闲时会先显示空闲，而不是列出全部话题问题。暂停按钮按原规则关闭自动；继续聊天不会自动重开。切换模式、场景、人物、独立体验组合、检索开关或修改API配置也会关闭自动。

状态通常约每秒刷新，真正自动检查仍约30秒一次；调度间隙超过90秒会重新等待，不补跑。显示的时间只是相应门槛的剩余时间，不能预约或保证说话。主窗口原提示区保留本次完成结果，自动控制区是当前状态，不是请求历史或模型思考解释。

## 次数与费用

自动模型请求尝试、自动本地开口分别受滚动小时2次 / 本次程序会话6次限制。手动聊天、手动评估不计入自动配额；失败、合法沉默、发出后取消也不退回请求尝试。纯本地门槛阻止不计请求，不新建冷却。流程模拟不调用API，不占模型请求次数，但自动采用的本地消息计开口次数。

这些数字不是token量、消费金额或全部调用账单。配额只在当前进程有效，程序重启会重置，开关不会恢复。保留原时机和交易边界，详情见[第十阶段说明](第十阶段使用说明.md)。

## 可选的一次白天体验

无需重验旧阶段。若你愿意体验真实自动语言，可自行：

1. 白天选择主人私聊，核对自己使用的模型配置，准备一个真实想继续、已人工确认的有效话题。已有合适话题可直接用。
2. 关闭子窗、处理旧草稿和未发送输入，亲自开启两项自动开关，正常使用一段时间。点击和输入会重新计空闲，真实默认等待仍为10分钟。
3. 观察一次自然开口，或一次有解释的等待。开口后接一句话；若表达不自然，使用原回复旁“评价这句”入口。
4. 点击“停止自动”或关闭窗口，明确结束。本地试聊不需要微信。

开发没有替你开启体验或补采样本。愿意反馈时，最少告诉我们“什么时候期待开口、实际显示什么、是否打扰、哪句不自然”。只有需要分析措辞时，再明确授权少量相关文本；不需要整库、Key或全量请求。

反馈入口不会自动训练模型。自动采用仍没有普通成功exchange同等级的瞬时直接取数清单，原证据入口会诚实降级；不能从今天的资料反推当时模型为什么这么说。没有真实样本，本轮不调整人格、频率或沉默规则。
